## Card tutorial.dne.001
skill: tutorial.dne
answer-type: number
answer: DNE
wrong: 0 => The limit is not 0: it does not exist, so type DNE.

### Question
The limit \(\displaystyle \lim_{x \to 0} \frac{|x|}{x}\) does not exist. Type the answer that says so.

### Hints
1. Type `DNE`, short for "does not exist".

### Solution
0. [tutorial.dne] Type it: `DNE`. The quotient is \(1\) for \(x > 0\) and \(-1\) for \(x < 0\), so there is no single limit.
